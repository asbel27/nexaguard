Política de Privacidad

Última actualización: 26 de Octubre de 2026

1. Compromiso con la Privacidad por Diseño

En NexaGuard diseñamos nuestra tecnología bajo el principio de minimización de datos. Creemos firmemente que la seguridad no debe comprometer la privacidad ni la soberanía de sus datos.

2. Datos que Procesa el Plugin Local en WordPress

El plugin NexaGuard opera de manera autónoma en su propio servidor web. Los análisis forenses, la detección heurística, la cuarentena de archivos infectados y el registro de eventos del cortafuegos (WAF) se almacenan localmente en la base de datos y sistema de archivos de su instalación de WordPress. NexaGuard no transmite contraseñas, contenido de páginas, datos de usuarios ni credenciales administrativas a servidores externos.

3. Conexiones a Servicios Externos Opcionales

El plugin solo establece comunicaciones externas en los siguientes casos expresamente documentados:

  • API Oficial de Checksums de WordPress.org: Para verificar la integridad de los archivos del núcleo de WordPress (se envían únicamente la versión de WordPress y el idioma de instalación; sin datos personales).
  • Red de Inteligencia de Amenazas NexaGuard (Opt-in): Si el usuario activa voluntariamente las firmas en la nube, se verifica periódicamente si existen nuevas firmas heurísticas. Se transmite el nombre de dominio y la versión del plugin para entregar la base de datos de firmas adecuada.
  • API de Validación de Licencia NexaGuard: Al ingresar una clave PRO o activar una membresía, se valida la autenticidad del token y se asocia al dominio autorizado.

4. Datos Recopilados en nexaguards.com

En nuestra plataforma web recopilamos la información indispensable para la facturación y entrega del servicio (nombre, correo electrónico y detalles de la transacción procesados de forma segura a través de pasarelas certificadas como PayPal o Stripe). Nunca almacenamos números completos de tarjetas de crédito en nuestros servidores.

5. Derechos del Usuario (RGPD / CCPA)

Usted tiene derecho a acceder, rectificar o solicitar la eliminación total de sus datos de cuenta en nexaguards.com en cualquier momento enviando una solicitud a contacto@nexaguards.com.
